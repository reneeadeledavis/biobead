# BioBead

**BioBead** is a hydrogel microbial delivery system designed to support plant-microbe symbioses in dynamic soil environments. It serves as both a carrier and a living interface—delivering beneficial fungal, bacterial, or mycorrhizal consortia in bead form to plant roots.

## 🌱 Purpose
BioBead enables precise, tunable inoculation strategies in ecological restoration and sustainable agriculture. Each bead can be customized to:
- Deliver targeted microbial consortia
- Respond to environmental cues (e.g., moisture, pH)

## 🔬 Current Focus Areas
- Characterizing microbial activity across soil types and host plant interfaces
- Developing **SmartBeads** that change visibly or functionally in response to soil conditions

## ⚙️ Technologies Used
- Alginate-based encapsulation
- Fungal and bacterial co-culture
- Microscopy, FISH, and bioinformatics tools (e.g., DESeq2, Kallisto)

## 🚧 Status
This repository serves as an open, evolving lab notebook and prototype archive for the BioBead platform. It includes protocols, experiment logs, images, and computational analyses.
